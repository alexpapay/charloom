# Security

Please do not post exploit details or private images in public issues. Use GitHub's private vulnerability reporting when available, or contact the maintainer through their GitHub profile before sharing sensitive details.

The latest main branch is the supported version during early development. Keep Pillow, NumPy and the web stack updated. The public playground is for small interactive conversions, not bulk processing.

Run behind HTTPS and a reverse proxy with body-size, timeout and rate limits. Keep the container non-root, resource-limited and bound to loopback. Use the CLI for sensitive or large images.
